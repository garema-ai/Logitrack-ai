What this agent actually does

Explainable analysis rules, prioritized actions, optional LLM-assisted explanations

Decision pipeline: CSV records → validation → KPI calculations → exception rules → P0/P1/P2 suggested actions → human review.

Definitions: Critical stockout risk = marked-critical item with <5 days of cover. Aging inventory = oldest unit age ≥90 days. Pending overdue shipment = planned delivery date is earlier than analysis date, with no confirmed delivery by that date. Vendor overdue = unpaid and past due.

Not included: Autonomous purchase ordering, real-time tracking, SAP integration, live warehouse or transporter data, predictive machine learning, or business-approved controls. For CSV upload, dynamic calculations, and an optional LLM explanation mode, run the Python Streamlit application included in this repository.
